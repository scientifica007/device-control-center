# خطة تطوير Device Control Center

## v0.1.0 — نموذج تجريبي
- [x] واجهة GTK3 عربية RTL خفيفة متوافقة مبدئيًا مع Ubuntu 24.04.
- [x] قراءة بطارية Bluetooth عند دعمها بواسطة BlueZ أو UPower.
- [x] اكتشاف الأجهزة والاتصال والفصل والإقران حسب السماح.
- [x] مراقبة وضبط مصادر إدخال وإخراج الصوت.
- [x] مراقبة حالة Wi-Fi الأساسية وتصدير JSON.
- [x] اختبارات وحدات تستند إلى عينات فعلية لسماعة Condor Aero 1.
- [ ] اختبار تشغيلي ميداني موثق على حاسوب HP 630 وسماعة Condor Aero 1.

## v0.1.1 — إصلاح بدء التشغيل
- [x] تثبيت Gdk 3.0 صراحة قبل الاستيراد مع GTK 3.0.
- [x] إضافة اختبار واجهة GTK باستخدام Xvfb في البناء الآلي.
- [ ] التحقق الميداني من عمل الواجهة على Ubuntu 24.04 LTS لدى المستخدم.

## v0.2 — تشخيص وموثوقية
- الانتقال تدريجيًا إلى إشعارات D-Bus من BlueZ لتقليل الاستطلاعات.
- تنبيهات سطح المكتب للبطارية المنخفضة، مع عتبات قابلة للضبط.
- متابعة التغيرات في الإشارة وتسجيل فترات الاتصال والانقطاع.
- قياس مستوى الصوت الفعلي (dBFS) بموافقة المستخدم.
- عرض نوع ملف الصوت A2DP/HFP وسماح تغييره إن دعمه النظام.

## v0.3 — تكامل الهاتف
- تكامل اختياري مع KDE Connect أو تطبيق Android مرافق.
- إظهار بطارية الهاتف، نقل الملفات ومراقبة الحالة.
- قناة تحكم محلية مع اقتران وتفويض واضحين.

## v0.4 وما بعد
- دعم إضافات جهازية modular plugins.
- قواعد أتمتة محلية؛ تشخيص إضافي وطباعة تقارير.
- تقدير مسافة RSSI على سبيل التجربة فقط، مع توضيح عدم الدقة.

## القيود
لا تُختلق بيانات للبطارية أو الإشارة أو المسافة. لا صلاحيات مرتفعة افتراضيًا، ولا مراقبة خفية أو اتصال شبكي دون موافقة المستخدم.
